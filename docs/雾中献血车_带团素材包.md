# 雾中献血车：带团素材包

本素材包用于配合《雾中献血车》前置新手本开团。它不是模组正文，而是主持时可以直接使用的工具：玩家手卡、证物图、NPC 台词卡、场景速查、追逐与战斗提示、结局播报和正篇接续钩子。

## 使用方式

素材分为两类。

| 类型 | 用法 |
|---|---|
| 玩家可见手卡 | 可以直接发给玩家，适合放进聊天群、VTT、KP 网站或打印 |
| KP 专用速查 | 只给守秘人使用，包含隐藏真相、兜底推进和怪物行为 |

建议守秘人开团前准备好 7 张玩家手卡，按场景逐张发出。不要一次性发完，线性短团的节奏来自“玩家刚好拿到下一步钥匙”。

## 手卡发放顺序

| 编号 | 名称 | 发放时机 | 玩家能看懂什么 |
|---|---|---|---|
| 1 | 献血活动传单 | 开场前或场景一初到 | 这是正规校园公益活动 |
| 2 | Henry 的献血登记卡 | Henry 失踪后搜登记桌 | Henry 被标记复筛 |
| 3 | 复筛名单截屏 | 医务帐篷电脑或彼得帮忙读屏 | Henry 和 Yu Hui 同在名单上 |
| 4 | R-13 转运单 | 医务帐篷垃圾袋或艾米交出 | 下一站是医学楼后巷 |
| 5 | V-RH null 银标贴纸 | 标签打印机或血袋样本 | 医院在筛特殊血源 |
| 6 | 车载记录仪摘要 | 医学楼后巷车内 | Henry 仍活着，被拖向河边 |
| 7 | 校方事故通报 | 余波阶段 | 官方开始封口 |
| 8 | 余辉邮件 | 接入正篇时 | 进入《温莎血月》正篇 |

# KP 一页速查

## 时间轴

| 时间 | 事件 | KP 用法 |
|---|---|---|
| 18:30 | 献血活动开始，学生排队 | 让玩家熟悉 NPC 和帐篷结构 |
| 19:10 | Henry 献血后听见冷藏箱声音 | 第一次异常提醒 |
| 19:20 | 帐篷短暂停电，Henry 失踪 | 事件启动 |
| 19:35 | 医务帐篷可查到复筛名单 | 给出 V-RH null 与 R-13 |
| 20:05 | 医学楼后巷发现破箱与拖痕 | 从社交调查转惊悚 |
| 20:30 | 旧艇库救援与战斗 | 新手战斗教学 |
| 23:30 | 校方与医院封口，余辉埋钩子 | 接正篇 |

## 场景目标

| 场景 | 必须完成 | 若玩家卡住 |
|---|---|---|
| 校园献血点 | 确认 Henry 没被正常转移 | 彼得指出献血车去医学楼后巷 |
| 临时医务帐篷 | 拿到 V-RH null 和 R-13 转运单 | 艾米接电话后直接写下后巷地址 |
| 医学楼后巷 | 发现拖痕通向旧艇库 | 昏迷司机醒来说“它往河边去了” |
| 河边旧艇库 | 救 Henry，处理幼体 | Henry 用敲击声提示位置 |
| 余波 | 决定证据和 Henry 去向 | 余辉出现或次日发邮件 |

## 三条必须线索

| 线索 | 最早出现 | 作用 |
|---|---|---|
| V-RH null | 场景二 | 告诉玩家医院在筛特殊血源 |
| R-13 冷藏箱 | 场景一/三 | 证明献血车运输活体样本 |
| 七瓣/七冠痕迹 | 场景三/四 | 接到温莎、血井和正篇意象 |

## 兜底原则

若玩家检定失败，不要说“没有线索”。改用低质量线索。

| 原线索 | 成功版本 | 失败版本 |
|---|---|---|
| 献血车去向 | 看清医学楼后巷地址 | 只看见车往医学楼方向开 |
| V-RH null 标签 | 完整读出候选血源缩写 | 只看到 “V-RH” 和 “cand.” |
| 车载记录仪 | 导出 Henry 被拖走画面 | 听见记录仪音频里 Henry 呼救 |
| 拖痕 | 追踪到旧艇库 | 彼得或艾米说那边只有旧艇库 |
| 幼体弱点 | 明确 UV、盐、银有用 | 看到黏丝遇盐收缩 |

# 追逐与战斗速查

## 警觉等级

| 等级 | 触发 | 后果 |
|---|---|---|
| 0 | 玩家低调调查 | NPC 正常反应 |
| 1 | 被医院人员记住外貌 | 格林优先阻拦玩家 |
| 2 | 玩家公开威胁或拍照 | 多 1 名安保，抢手机 |
| 3 | 玩家报警或大闹帐篷 | 医院代表提前出现 |
| 4 | 玩家交出全部证据 | 余波中医院掌握主动 |

## Henry 状态轨

| 状态 | 触发 | 表现 |
|---|---|---|
| 稳定 | 玩家快速追踪并救援 | 能说出关键证词 |
| 失温 | 场景三拖延较久 | 旧艇库救援多 1 轮 |
| 昏迷 | 幼体成功吸血或玩家严重拖延 | 需要背负撤离 |
| 被转院 | 交给拉德克里夫医院 | 正篇只留下删改病历 |

## 温莎幼体行动表

每轮任选一项。

| 条件 | 行动 |
|---|---|
| 有角色流血 | 优先扑向流血者 |
| 有角色拿 UV 灯 | 绕后或扑灭灯 |
| 玩家正在救 Henry | 缠绕救援者 |
| HP 降至 3 以下 | 逃向河水入口 |
| 被盐或强光逼退 | 用 Henry 的声音求救 |

## 环境物品效果

| 物品 | 效果 |
|---|---|
| 旧桨架 | 推倒后幼体本轮闪避惩罚骰 |
| 救生衣柜 | 抵消一次扑咬奖励骰 |
| 粗盐袋 | 撒中幼体造成 1 点伤害并逼退 |
| 塑料布 | 成功罩住可让幼体 1 轮无法缠绕 |
| UV 灯 | 幼体攻击惩罚骰，持续 3 轮 |
| 消防斧 | 切黏丝或破木艇时给奖励骰 |

# 结局播报

## 干净胜利

> 黎明前，Henry 在安全的房间里终于睡着。桌上摆着 R-13 照片、V-RH null 标签、七瓣骨环和转运单。窗外校园恢复平静，像什么都没发生过。但你们知道，有一辆献血车曾从这里带走活着的样本，也知道医院会回来寻找失手遗落的证据。

## 留下后患

> Henry 活下来了，但泰晤士河湾方向一整夜都有水鸟惊飞。第二天清晨，有人发现划船社码头上挂着一层白色蜕皮，薄得像透明手套。它已经不在艇库里了。它记得血的味道，也记得你们的脸。

## 被迫沉默

> 医院的车带走了 Henry，也带走了大部分证据。校方邮件把事件称为“设备故障引发的医疗恐慌”。你们手里只剩一张模糊照片、一小撮盐白粉末，和那句无法写进报告的话：箱子里的东西会学人说话。

# 正篇接续

若继续进入《温莎血月》，把正篇开场邮件替换为以下版本：

> 你们见过那辆献血车，所以我只能写给你们。R-13 不是事故，医院在筛人。Henry Lane 只是第一次外泄。若我明天没来上课，请去找查尔斯，他知道负三层在哪。

根据玩家保存的证据，给正篇奖励。

| 保存内容 | 正篇奖励 |
|---|---|
| 七瓣骨环 | 首次见血井时理智损失降低一级 |
| V-RH null 标签 | 献血中心调查获得奖励骰 |
| 格林录音 | 与莫迪谈判时可作为筹码 |
| R-13 视频 | 夏洛特或莫里亚蒂更快信任 |
| Henry 存活 | 正篇可提供一次低风险确认线索 |
